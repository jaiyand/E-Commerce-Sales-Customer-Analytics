# 🛒 E-Commerce Sales & Customer Analytics

### **Data Analysis Project using Python, MySQL & Power BI**

## 📌 Project Overview

This project analyzes Brazilian e-commerce data to understand **sales performance, customer behaviour, product categories, and delivery performance**.

I used Python for data cleaning, MySQL for SQL analysis, and Power BI to build an interactive dashboard.

## 🛠️ Tools & Technologies

- **Python** – Data cleaning and analysis
- **Pandas** – Data manipulation
- **MySQL** – Database management and SQL queries
- **Power BI** – Interactive dashboards
- **DAX** – KPI calculations

## 📊 Dataset Summary

| Metric | Total |
|---|---:|
| Orders | 99,441 |
| Unique Customers | 96,096 |
| Order Items | 112,650 |
| Products | 32,951 |
| Sellers | 3,095 |

## 💡 Key Business Insights

### **1. Sales Performance**
- Gross item value was approximately **R$ 15.84 million**.
- Average order value was approximately **R$ 160.58**.
- These metrics help measure overall sales performance.

### **2. Customer Retention**
- **96,096 unique customers** were identified.
- **93,099 customers** placed only one order.
- The repeat customer rate was approximately **3.12%**.

**Insight:** Customer retention is an opportunity for improvement through loyalty programs and targeted offers.

### **3. Order Fulfilment**
- **96,478 orders** were delivered.
- Other orders had statuses such as shipped, canceled, unavailable, or processing.

**Insight:** Order status analysis helps monitor fulfilment performance.

### **4. Product Categories**
- Compared product categories by gross item value.
- Identified the top 10 revenue-generating categories using Power BI.

**Insight:** Category analysis helps businesses understand which products contribute most to sales.

### **5. Customer Geography**
- Analyzed customer distribution across Brazilian states.
- Compared the top 10 states by customer count.

**Insight:** Geographic analysis helps identify important customer markets.

### **6. Monthly Trends**
- Analyzed monthly revenue and order counts.
- Used a Year slicer to compare performance across years.

**Insight:** Monthly trends help identify changes in sales activity over time.

### **7. Delivery Performance**
- Analyzed delivery duration and delay compared with estimated dates.
- Used delivery metrics to evaluate fulfilment efficiency.

**Insight:** Delivery analysis can help identify opportunities to improve the customer experience.
